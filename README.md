1. Qu'est-ce que le Full Stack ?

Le Full Stack est une approche de développement Web qui consiste à travailler sur les différentes parties d'une application : le frontend (interface utilisateur), le backend (logique serveur) et la base de données (stockage des informations).

2. Rôle de MongoDB

MongoDB est une base de données NoSQL qui permet de stocker et de gérer les données sous forme de documents organisés dans des collections.

3. Rôle d'Express.js

Express.js est un framework Web pour Node.js qui facilite la création de serveurs et d'API REST. Il permet de gérer les routes, les requêtes et les réponses HTTP.

4. Rôle d'Angular

Angular est un framework frontend basé sur TypeScript qui permet de créer des interfaces Web dynamiques et interactives à l'aide de composants.

5. Rôle de Node.js

Node.js est un environnement d'exécution JavaScript qui permet d'exécuter du code JavaScript côté serveur, en dehors du navigateur.

6. Fonctionnement général de l'architecture MEAN

L'architecture MEAN repose sur quatre technologies qui travaillent ensemble :

Angular : affiche l'interface utilisateur et envoie des requêtes HTTP.

Express.js : reçoit et gère les requêtes HTTP.

Node.js : exécute le code JavaScript côté serveur.

MongoDB : stocke et récupère les données.

Le fonctionnement général est le suivant :

L'utilisateur interagit avec l'interface Angular.

Angular envoie une requête HTTP au backend.

Express.js reçoit et traite la requête avec Node.js.

Le backend communique avec MongoDB pour récupérer ou enregistrer les données.

Le serveur renvoie une réponse à Angular.

Angular affiche le résultat à l'utilisateur.
